Proyecto Grupal: Entorno Animado 3D

Pipeline: Animación Humanoid & Control

Pipeline de Configuración, Rigging y Control 3D

Proceso seguido para importar personajes, configurar animaciones y preparar su funcionamiento dentro de Unity.

1. Importación de Modelos 3D

Se descargaron los personajes 3D y se incorporaron al proyecto de Unity. También se verificó que las texturas y materiales se cargaran correctamente.

2. Configuración en Mixamo

Los modelos fueron cargados en Mixamo para generar automáticamente el esqueleto y descargar las animaciones necesarias para el proyecto.

3. Configuración Humanoid

En Unity se cambió el tipo de animación a Humanoid para que el personaje pudiera utilizar correctamente las animaciones importadas.

4. Revisión del Esqueleto

Se verificó que los huesos del personaje estuvieran correctamente asignados para evitar errores o deformaciones durante las animaciones.

5. Configuración del Animator

Se crearon los controladores de animación y se asignaron diferentes bailes a los personajes para utilizarlos dentro de la escena.

6. Integración Final

Se asignó el Animator Controller al personaje dentro de Unity, vinculando el modelo con la animación seleccionada para completar su funcionamiento en la escena.
